# 📈 Эконометрика — мои конспекты

## Основные понятия

- **Регрессия** — зависимость одной переменной от других
- **МНК** — метод наименьших квадратов
- **Гетероскедастичность** — непостоянная дисперсия ошибок
- **Мультиколлинеарность** — корреляция между признаками

---

## Модели

| Модель | Применение |
| :--- | :--- |
| Линейная регрессия | Прогноз |
| Логит/Пробит | Бинарный выбор |
| Панельные данные | Наблюдения во времени |
| VAR | Временные ряды |

---

## Пример: линейная регрессия

```python
import statsmodels.api as sm
import numpy as np

X = np.array([[1, 2], [2, 4], [3, 6], [4, 8]])
y = np.array([3, 6, 9, 12])

X = sm.add_constant(X)
model = sm.OLS(y, X).fit()
print(model.summary())
